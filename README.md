# FUTURE_DS_01 – Business Sales Dashboard (Power BI)

## Project Overview
This project presents a business sales dashboard built using Power BI to analyze e-commerce sales data and generate actionable insights for decision-making.

---

## Business Objectives
- Track key sales and revenue metrics
- Identify top-performing products and categories
- Analyze sales trends over time
- Support strategic business decisions

---

## Technical Implementation

### 1. Data Preparation
- Imported the source datasets into Power BI.
- Used Power Query to inspect, clean and transform the data.
- Prepared the data for analysis and reporting.

### 2. Data Modelling
- Established relationships between the relevant tables.
- Organised the data model to support consistent reporting and analysis.
- Used the model to connect business data across the dashboard.

### 3. DAX Measures

Created calculated measures using DAX to support business performance analysis.

The DAX functions used included:

- `SUM()` — aggregation of numerical values.
- `CALCULATE()` — evaluation of measures under modified filter contexts.
- `DIVIDE()` — division with protection against division-by-zero errors.
- `COUNTROWS()` — counting records in a table.
- `AVERAGE()` — calculating average values.
- `DISTINCTCOUNT()` — counting unique values.

### 4. Dashboard Development

The dashboard was designed to communicate key business performance indicators, including:

- Sales and revenue performance.
- Product and category performance.
- Sales trends over time.
- Regional performance.
- Business insights to support decision-making.

### 5. Evidence and Project Files

The repository includes project resources organised into:

- `data/` — source datasets.
